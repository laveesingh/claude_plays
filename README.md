# claude_plays

A collection of apps. Each app lives in its own top-level directory.

| App | Platform | Description |
|---|---|---|
| [`life-coach/`](life-coach/) | iOS (SwiftUI) | A Claude-powered agent that merges a full-time life coach with a personal assistant: it timeboxes your day, verifies commitments against HealthKit and your calendar, pings you block-by-block, and critiques you with receipts. |

Future apps are added as peer directories.
